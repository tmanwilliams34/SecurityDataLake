# SecurityDataLake

An AWS project where security information gets processed into graphs and spreadsheets. 
An ML trained on this information predicts from current information for future threats.

## Background
This project was mainly for our class project studying Data Engineering and Machine Learning. 
It became one of the enjoyable projects I've yet done.

## Key Features
- Data is transformed and processed into easily understandable graphs and structures.
- A machine takes future information and divides it into Malice and Benign catagories.
- A live system log displays different alerts

## Tech Stack
- Language: Python, SQL
- Framwork: AWS s2, Glue, Athena, Cloud 9, Jupiter notebook
- Infra: AWS

## Technical Challanges / Design Decisions
The massive size of data made it difficult to work on locally.
Learning AWS was a challenge but a good test.
